# make-video

초보자가 한 줄로 요청해도 같은 기준으로 영상이 나오게 하는 진행표. 기준 값은 `CLAUDE.md`가 가리키는 docs에서만 온다.

## 순서

```
BRIEF → 레퍼런스 정리 → 장면표 [승인 1] → 스냅보드 [승인 2] → 영상
```

### 0. BRIEF (메인이 직접 묻는다)

`<영상이름>`을 짧은 영어 소문자로 정하고 `out/<영상이름>/BRIEF.md`에 적는다. 한 번에 묻고, 질문마다 기본값을 같이 준다. "기본값"이라고 하면 그대로 적는다.

1. **무엇을** 보여줄까? (기본값 없음 — 꼭 받는다. `docs/design.md` 6장 화면 목록을 보여주며 묻는다)
2. **몇 초**? (기본값: 뼈대 레퍼런스 길이)
3. 레퍼런스 세 질문
   - 레퍼런스는? (링크 · 파일. 기본값: `references/`에 있는 것)
   - 여러 개면 **뼈대**는 어느 것? (기본값: 가장 긴 영상)
   - 나머지는 각각 무엇만 맡을까? 구성 · 구도 · 카메라 · 전환 · 글자 배치 중 (기본값: art-director가 제안)

### 1. 레퍼런스 정리 — `art-director`

결과: `out/<영상이름>/refs.md`. 확인만 하고 넘어간다 (승인 아님).

### 2. 장면표 — `director` · **승인 1**

director가 `out/<영상이름>/scenes.md`에 **3안 요약**을 쓴다. 사람에게 3안을 보여주고 하나를 고르게 한다 (기본값: director 추천안).
고른 안으로 director가 장면표를 완성한다. critic이 판정한다.

### 3. 스냅보드 — `builder` · **승인 2**

builder가 장면마다 정지 화면을 만든다 (`out/<영상이름>/snapboard/`). critic 판정 → 사람에게 스냅보드를 보여주고 승인받는다.

### 4. 영상 — `builder`

승인된 스냅보드대로 `out/<영상이름>/project/`에 만들고 `out/<영상이름>/<영상이름>.mp4`로 렌더한다. critic 판정 → 통과하면 영상을 보여주고 끝.

## 게이트 (critic이 세는 것)

장면표 · 스냅보드 · 영상마다 critic이 같은 세 가지를 센다. 자세한 세는 법은 `.claude/agents/critic.md`.

| # | 항목 | 통과 |
|---|---|---|
| G1 | docs에 없는 숫자 (길이 · 곡선 · 색 · 크기) | 0개 |
| G2 | 화면에 없는 UI (`src/screens` · `src/parts`에 없는 것) | 0개 |
| G3 | 레퍼런스 반영 (`refs.md` 항목 중 들어간 비율) | 60% 이상 |

- 놓는 위치 · 정렬은 장면표에 "어느 화면 · 부품을 보고 정했는지"가 적혀 있으면 통과.
- **먼저 결과물을 보여주고**, 판정은 한 줄: `통과` 또는 `떨어짐 G1: <장면> <무엇>`.
- 떨어지면 해당 담당(director 또는 builder)이 고치고 다시 판정한다.
- **같은 장면의 같은 항목에서 2번 떨어지면 멈추고 사람에게 묻는다.** 묻기 전에는 docs · src를 고치지 않는다.

## 폴더 (`out/<영상이름>/`)

| 파일 | 누가 |
|---|---|
| `BRIEF.md` | 메인 |
| `refs.md` | art-director |
| `scenes.md` | director |
| `snapboard/` | builder |
| `project/` · `<영상이름>.mp4` | builder |
| `verdict.md` | critic (판정 기록, 단계마다 한 줄씩 추가) |

## 하지 않는 것

- 승인 1 · 2를 건너뛰지 않는다 (사람이 "멈추지 말고"라고 해도 BRIEF에 적고 따른다).
- 에이전트에게 docs 내용을 옮겨 적어 넘기지 않는다. "motion.md 3장 참고"처럼 볼 곳만 넘긴다.
